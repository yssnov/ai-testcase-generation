Legend used inside documents:

- **[VERIFIED]** — supported by our interviews, data, or a cited source.
- **[ASSUMPTION]** — our belief, not yet checked. Each assumption names how it will be checked.
- **TEAM TODO** — work the team must still do; remove the marker when done.
